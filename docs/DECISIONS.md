# 项目愿景与决策记录

## 愿景

用 LLM / AI Agent 作曲、编曲，用代码合成真实乐器的声音，组合成乐队编制（先摇滚乐队，远期小型交响乐团）。
可以编辑曲谱，也可以调整每种乐器的演奏细节。

## 整体架构（已认可）

```
LLM Agent（作曲/编曲）
   │  输出符号化乐谱（文本 DSL）
   ▼
① 乐谱表示层   音符、和声、配器、力度、演奏法
   ▼
② 演奏渲染层   谱面 → 演奏：时值微调、力度曲线、颤音、滑音、连奏
   ▼
③ 声音合成层
   ▼
④ 混音层       声像、EQ、压缩、混响、母带
   ▲
⑤ 编辑界面     五线谱 + 钢琴卷帘 + 表情曲线，双向同步
```

- 走“符号化 + 合成”路线，不用端到端音频生成（Suno/Udio 类），因为后者无法编辑。
- LLM 只写自定义的中间 DSL（JSON/YAML），由代码编译成 MIDI / MusicXML。
- 数据模型分两层：**谱面**（作曲意图）和**演奏**（逐音的偏移和曲线）分开存储。
- 不同音源的演奏法接口不统一，需要抽象的演奏法层，再给每个音源写映射。

## 物理建模要点（摇滚乐队）

通用原则：
- 拆成“激励 → 共振体 → 辐射/拾音”，各部分单独建模、单独校准。
- 补齐“不理想”的细节：非谐性（色散）、随频率变化的损耗、双偏振和拍频、张力调制（音高下滑）、碰撞非线性（打品、slap、军鼓响弦）。
- 每个音加入微小随机扰动，避免“机关枪效应”。
- 保留振动状态，新的激励作用在当前状态上（物理建模相对采样的最大优势）。
- 加入非音乐的声音：刮弦、滑弦、踏板声等。
- 校准：用真实单音录音拟合非谐系数和各泛音衰减；用可微分模型（JAX）+ 多分辨率 STFT 损失自动拟合参数；最终以盲听 A/B 为准。
- 离线渲染，可以用较昂贵的模型和高过采样倍数。

各乐器方案和预期真实度：

| 乐器 | 方案 | 预期 |
|---|---|---|
| 电吉他 | 扩展 Karplus-Strong / 数字波导 + 拾音器模型 + 品碰撞；放大器用 WDF 电路建模，箱体用 IR 卷积 | ⭐⭐⭐⭐⭐ |
| Hammond / Rhodes | 转轮加法合成 + Leslie 模型 / 音叉 + 拾音器非线性 | ⭐⭐⭐⭐⭐ |
| 电贝斯 | 同吉他框架，加强非谐性、张力调制、slap/pop 碰撞 | ⭐⭐⭐⭐ |
| 嗵鼓、底鼓 | 圆膜模态合成（或 2D FDTD）+ 鼓腔耦合 + 音高下滑 | ⭐⭐⭐⭐ |
| 军鼓 | 双鼓皮耦合 + 响弦碰撞非线性 | ⭐⭐⭐ |
| 钢琴 | 琴槌非线性 + 多弦耦合 + 音板 + 共鸣 | ⭐⭐⭐ |
| 镲片、踩镲 | 非线性板（von Kármán）或模态 + 非线性耦合 / 滤波噪声近似 | ⭐⭐ 最大短板，必要时临时用采样 |

工具候选：Faust（`physmodels`）、STK、JAX、numba、C++/Rust 渲染引擎、`chowdsp_wdf`。

建议的第一步：电吉他单弦模型 + 简单真空管失真 + 箱体 IR，顺便搭出模块化框架。
