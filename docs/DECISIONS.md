# 项目愿景与决策记录

## 愿景

用 LLM / AI Agent 作曲、编曲，用代码合成真实乐器的声音，组合成乐队编制（先摇滚乐队，远期小型交响乐团）。
可以编辑曲谱，也可以调整每种乐器的演奏细节。

## 整体架构（已认可）

```
LLM Agent（作曲/编曲）
   │  输出符号化乐谱（文本 DSL）
   ▼
① 乐谱表示层   音符、和声、配器、力度、演奏法
   ▼
② 演奏渲染层   谱面 → 演奏：时值微调、力度曲线、颤音、滑音、连奏
   ▼
③ 声音合成层
   ▼
④ 混音层       声像、EQ、压缩、混响、母带
   ▲
⑤ 编辑界面     五线谱 + 钢琴卷帘 + 表情曲线，双向同步
```

- 走“符号化 + 合成”路线，不用端到端音频生成（Suno/Udio 类），因为后者无法编辑。
- LLM 只写自定义的中间 DSL（JSON/YAML），由代码编译成 MIDI / MusicXML。
- 数据模型分两层：**谱面**（作曲意图）和**演奏**（逐音的偏移和曲线）分开存储。
- 不同音源的演奏法接口不统一，需要抽象的演奏法层，再给每个音源写映射。

| 2026-10-05 | **混音层 v1**：每个声部 自动增益 → 高通 → 3 段 EQ → 压缩（补偿增益恢复 RMS，只改动态不改平衡）→ `gain_db` → `pan`，并按 `reverb` 发送到整支乐队共用的 FDN 空间（`space: dry / room / studio / hall`，默认 `studio` 约 0.8 秒，送入前高通 150 Hz）；主输出 总线压缩（`master.style: rock / gentle / none`）→ 调到目标响度（BS.1770 积分响度，`master.loudness` 默认 -14 LUFS）→ 真峰值限幅（4 倍过采样，5 ms 预读，-1 dBTP），代替原来的峰值归一化。各乐器类型有调好的默认值（贝斯 `heavy` 压缩、不送混响，吉他高通 90 Hz、350 Hz 削 1.5 dB 等）；`comp`、`reverb`、`space`、`style` 用名字，`eq` 用 dB。`mix:` 现在会校验（以前完全不查）。`beat render` 打印混音报告，限幅器压缩超过 6 dB 时警告并指出位置和该调的键；`--mix off` 走旧的求和路径做对比 | 各乐器原来各在各的空间（鼓有房间，吉他、贝斯是干声），叠在一起不像唱片；单下响的鼓会让整首歌被峰值归一化压小。名字沿用风琴 `registration` 的思路，Agent 选名字比调数字可靠；Agent 听不到声音，混音报告是它唯一的反馈。用户确认了三项默认值：-14 LUFS、保留鼓自己的房间（只少量送进共用空间，不改已认可的鼓声）、`studio`。试做时发现鼓的瞬态比 RMS 高约 21 dB，限幅器在吊镲、叮叮镲上压到 7 dB，80 ms 的释放会让整个乐队跟着被压下去；加大鼓的压缩没用（补偿增益把瞬态又抬上来），所以鼓声部自带一个快速削峰（RMS 以上 18 dB，释放 20 ms，不开放给 DSL）：演示曲限幅器最大 7.3 → 3.5 dB。渲染多约 5 秒。侧链和按段落自动化放到 v2 |

## 物理建模要点（摇滚乐队）

通用原则：
- 拆成“激励 → 共振体 → 辐射/拾音”，各部分单独建模、单独校准。
- 补齐“不理想”的细节：非谐性（色散）、随频率变化的损耗、双偏振和拍频、张力调制（音高下滑）、碰撞非线性（打品、slap、军鼓响弦）。
- 每个音加入微小随机扰动，避免“机关枪效应”。
- 保留振动状态，新的激励作用在当前状态上（物理建模相对采样的最大优势）。
- 加入非音乐的声音：刮弦、滑弦、踏板声等。
- 校准：用真实单音录音拟合非谐系数和各泛音衰减；用可微分模型（JAX）+ 多分辨率 STFT 损失自动拟合参数；最终以盲听 A/B 为准。
- 离线渲染，可以用较昂贵的模型和高过采样倍数。

各乐器方案和预期真实度：

| 乐器 | 方案 | 预期 |
|---|---|---|
| 电吉他 | 扩展 Karplus-Strong / 数字波导 + 拾音器模型 + 品碰撞；放大器用 WDF 电路建模，箱体用 IR 卷积 | ⭐⭐⭐⭐⭐ |
| Hammond / Rhodes | 转轮加法合成 + Leslie 模型 / 音叉 + 拾音器非线性 | ⭐⭐⭐⭐⭐ |
| 电贝斯 | 同吉他框架，加强非谐性、张力调制、slap/pop 碰撞 | ⭐⭐⭐⭐ |
| 嗵鼓、底鼓 | 圆膜模态合成（或 2D FDTD）+ 鼓腔耦合 + 音高下滑 | ⭐⭐⭐⭐ |
| 军鼓 | 双鼓皮耦合 + 响弦碰撞非线性 | ⭐⭐⭐ |
| 钢琴 | 琴槌非线性 + 多弦耦合 + 音板 + 共鸣 | ⭐⭐⭐ |

### 电吉他模型的改进方向（v1 之后）

v1 试听“还可以”。下面是已知的可能改进，按大致优先级排列，还没有排期：

- **音色**：闷音段落高频偏少，chug 可能不够扎实（可以放宽闷音的高频损耗，或让闷音的起音更亮）；干净音色比旧版暗不少，主要是合成箱体 5.2 kHz 以上衰减得陡，可以调箱体或给 `clean` 加亮。
- **演奏法 v2**（2026-10-11 已做 `!sl`、`!bend`、`!release`、`!vib`、`!fall`、`!harm`，待试听）：以后可以加预推、向上滑出、推弦和揉弦的 MIDI 弯音输出、人工泛音和拨片泛音（pinch harmonic）。
- **弦的物理细节**：双偏振和拍频；张力调制已做（2026-10-13，固定 3 音分，可以改成随振幅变化）；打品等碰撞非线性；各弦的非谐系数和衰减用真实录音校准。
- **非音乐的声音**：拨片刮弦、换把滑弦声、松手时的手指噪声。
- **拾音器**：琴颈 / 琴桥拾音器可选（例如放进 `model:`），单线圈和双线圈的谐振差别。
- **放大器和箱体**：用 WDF 做电路级的电子管建模（含供电下垂和随弹奏力度变化的动态；2026-10-13 先给 `lead` 加了一个简单的下垂）；力度大时音色变亮（高增益下音量几乎不随力度变）；音箱底噪（乐句之间现在是数字静音，但底噪会贯穿整首歌，要和混音一起考虑）；换成录制的 IR，或让合成 IR 可选话筒位置。
- **分配到弦**：现在只看手位和不切断保持的音；以后可以允许在 `model:` 或记谱里指定弦或把位。
- **校准方法**：用可微分模型（JAX）+ 多分辨率 STFT 损失拟合真实单音录音，最终以盲听 A/B 为准。
- **贝斯**（2026-10-05 已换成弦模型，试听“挺不错”）：
  - 演奏方式：加拨片和 slap / pop（需要新的演奏法记号，或在 `model:` 里选拨弦方式）；手指拨弦时加手指碰弦、指甲声等起音细节。
  - 物理细节：张力调制目前只是线性滑回音准，可以改成随振幅变化；加弦打品的“咔啦”声（重拨或低把位时明显）；圆缠弦和平缠弦的音色差别。
  - 拾音器和放大器：P / J 拾音器可选；放大器加压缩和 DI + 箱体两路混合，让低频更稳、在乐队里更清楚。
  - 混音：贝斯和底鼓的低频分工（侧链或均衡），现在只靠自动电平。

### 鼓的物理模型（嗵鼓、底鼓、军鼓、整组耦合 v1 之后）

按“嗵鼓 → 底鼓 → 军鼓 → 整组耦合（共振、话筒和房间）→ 镲片换采样”的顺序推进。嗵鼓 v1 试听“还可以”，已知的疑点和下一步：

- **嗵鼓的疑点**：鼓槌接触时间 6–10 ms（偏长，可能偏闷）；嗵鼓相对其他鼓件比旧版轻约 4 dB（衰减比旧版快）；两个最低耦合模态都很响，听起来的音高可能和标称音高不一致。
- **嗵鼓细节**：鼓壳模态、击打点随力度变化、闷音（`model:` 里的阻尼预设）、鼓皮型号（单层 / 双层）。
- **底鼓**（v1 试听后设为默认）：鼓锤接触 14–20 ms，可能偏长；开孔的作用很小（只让延音少约 1 dB）；相对军鼓比旧版轻约 2 dB。以后可以加塑料锤（`model:` 里选）、踩住不放（buried beater）时的闷音、内外话筒分开并带延迟。
- **军鼓**（v1 试听“挺好”）：沙沙声在 0.2 秒内衰减约 40 dB，可能偏短；响弦的质量和弹簧是估计值，没有对照录音。以后：边击（rimshot）加鼓圈模态；侧击（`ss`）以鼓圈和鼓壳为主，并通过响弦响；松紧响弦（`model:` 里选）；关掉响弦（`snares off`）当作嗵鼓用。
- **整组**（v1 已做，待试听）：耦合是单向的，军鼓不会让嗵鼓共鸣（要双向就得把几个鼓放进同一个积分循环）；近距离话筒之间还没有串音；头顶话筒和房间的电平、混响时间是固定的，可以放进 `model:`（例如 `room: dry / studio / hall`）；镲片和踩镲已换成 DRSKit 采样（见上面的决定）。
- **校准**：用 ESPRIT 或 matrix pencil 从真实单击录音里提取模态频率、衰减和幅度。
- **采样镲片**（待试听）：高频比旧合成少（5 kHz 以上相对低频少 3–4 dB），真实镲片本来就没有方波那么刺，但要听听是否发闷；半开踩镲、镲片止音（grab）、叮叮镲镲边（shank）还没有记谱；DRSKit 的底鼓、军鼓、嗵鼓录音可以拿来校准物理模型（提取模态参数）。

### Hammond 风琴的改进方向（v1 之后）

v1 试听“挺好”，但还没有用真实录音校准，参数来自 B-3 / 122 的公开资料和频谱检查。可能的改进：

- **调音色**（最可能先动的几项）：Leslie 调幅深度（号角对纯音约 15 dB，可能偏深）；过载曲线和 `drive` 的手感；喀哒声的默认大小；整体亮度（`rock` 预设只开低音的 4 根拉杆，比旧版暗不少）；预设的拉杆组合可以对照名曲再调。

- **Leslie**：刹车（停转）；小节中间切换快慢（需要记谱或演奏层的标记）；箱体和房间更真实的反射（现在是每支话筒两三条固定路径）；号角的指向性随频率变化；122 功放用电路级建模。
- **音轮和触点**：音轮滤波电容和匹配变压器的频响；更完整的串音组合（现在只有同一隔间的 ±24、±48 个音轮）；松键喀哒声和按键喀哒声分开调；打击泛音的 soft / normal 音量。
- **扫描颤音**：用真实 LC 延迟线的抽头和扫描器的阶梯感，代替连续的调制延迟。
- **表情踏板**：音量低时保留低频（B-3 踏板的低音补偿）；小节内的踏板曲线（渐强、渐弱）。
- **编制**：下层键盘和脚踏低音键；两层键盘用不同的音栓配置。
- **校准**：对着真实 B-3 + Leslie 录音调 Leslie 调幅深度、多普勒幅度和过载曲线，最终以盲听 A/B 为准。
- **Rhodes**：下一件键盘乐器，需要先决定 DSL 是新增乐器类型还是 `piano` 的另一个引擎。
